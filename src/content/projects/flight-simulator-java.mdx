## Idea

A desktop application for entering airports and flights and then watching the traffic unfold on a map.
Time runs at ten simulated minutes per real second, each airport clears at most one departure per ten
minutes, and any plane can be redirected to another airport in mid-flight. The code is layered so that
the GUI knows about the services, the services know about the model, and the model knows about nothing else.
